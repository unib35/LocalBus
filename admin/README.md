# 관리자 페이지

LocalBus 운영용 웹페이지의 작업 폴더입니다.
현재 실행 가능한 웹 코드는 없으며, UI 설계와 기능 구현 단계에서 프레임워크 및 빌드 설정을 추가합니다.

## 첫 구현 범위

- 노선별 예상 소요시간과 마지막 갱신 상태 확인
- 교통정보 조회 실패 및 API 사용량 확인
- 방향별 보정시간과 교통 반영 설정 관리

시간표·공지·정류장 편집은 후속 범위입니다.
시간표 편집을 도입할 때는 초안·미리보기·게시 흐름과 기존 앱의 데이터 경로 호환성을 함께 설계합니다.

## 서버와의 관계

이 웹페이지는 `../server/`에서 제공하는 관리 API를 사용합니다.
관리자 인증과 변경 권한은 서버에서 검증하고, 변경 이력과 복구 수단을 마련합니다.
카카오 API 키나 데이터베이스 접근 비밀값은 브라우저 코드에 포함하지 않습니다.

공개 홈페이지와 약관은 기존 `../docs/`에 유지합니다.
관리자 페이지는 별도의 인증된 진입점으로 배포하며, `docs/`의 공개 페이지와 구분합니다.
